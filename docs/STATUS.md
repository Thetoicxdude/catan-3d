# 卡坦島 3D 戰略版：目前進度

線上可玩的卡坦島（基本版規則），地圖採鋼鐵雄心式的立體俯視戰略地圖。
遊戲頁面：https://claude.ai/artifact/HDKAKcGeLm5mr9pntYCbmN

## 已完成

**規則與單機**
- 完整基本版規則：開局擺放、擲骰產出、強盜（棄牌、移動、搶牌）、建造、發展卡、最長道路、最大騎士、港口與銀行交易、玩家間交易。
- 電腦對手（三種難度）、同一台裝置輪流（hot seat）、自動存檔與繼續。
- 規則引擎是純函式、可重播（seed 決定），有單元測試、完整對局模擬與網路序列化測試。

**地圖與操作**
- 立體地形：19 塊地形各有地貌（山脈、丘陵、森林、牧場、田地、沙漠），海岸、港口、海浪、雲影。
- 鏡頭：可調斜度（滑桿、Shift+滾輪、右鍵拖曳、Z/X、PageUp/PageDown）、可旋轉（Q/E、右鍵拖曳、雙指旋轉），Home 回正；拉遠時自動轉成俯視紙地圖。
- 地圖模式：地形、政治、產量熱度、資源。
- 可放置位置用白底黑框圓圈標示，任何角度、任何地形都看得清楚；強盜要移動時地形上會出現目標圈、橫幅提醒與「為什麼不能結束回合」的說明。

**寫實素材（全部 CC0，可商用、免署名）**
- 樹木與灌木：Poly Haven 的掃描模型（冷杉三種、箭袋樹兩種、路易波士灌木、蕨類），預先烘焙成多角度 impostor，數千棵樹也很順，轉動鏡頭時角度正確，並有隨風搖擺。
- 岩石、懸崖、樹樁、枯樹幹：Poly Haven 掃描模型，減面後以 instancing 擺放。
- 地表材質：Poly Haven 的 13 種地面照片材質（落葉林地、紅土、草地、碎石、岩壁、沙地等），保留各地形的辨識色調。
- 動物：Quaternius 的農場動物（綿羊、牛、馬、豬），骨架動畫預先烘焙成頂點動畫貼圖，整群動物只要一次繪製；會吃草、走動、跳。
- 素材放在頁面旁的 `assets/`（約 5 MB），背景下載；下載失敗時自動退回程式產生的場景。

**多人**
- 自訂房間：主持人開房、房間代碼加入、房間列表、斷線重連、觀戰；每位玩家的手牌以 ECDH + AES-GCM 加密，只有本人看得到。
- 官方房間（類似 FrontWars）：按「快速配對」自動進入開放中的官方房間；坐滿 4 人 3 秒後開戰，或 60 秒倒數結束由電腦補位開戰；同時出現兩個官方房間時，較新的會併入較舊的。

## 已知限制
- 線上對戰使用 claude.ai 的 room 功能：只有能開啟這個 artifact 的人（主持人透過「分享」分享過的對象）才會出現在房間與配對中。
- 線上流程已用本機的模擬房間完整測試（完整對局、斷線重連、觀戰；三人配對進同一房；五人配對時四人坐滿立即開戰、第五人自動開新房），尚未在真實多人環境實測。
- 素材取捨：藍花楹（208 MB）太大未納入；boulder_01 掃描無法減面而捨棄；部分 Poly Haven 植物（松樹苗、灌木）的 glTF 缺少透明貼圖，未採用。

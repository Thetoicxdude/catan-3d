# 卡坦島 3D 戰略版：目前進度

線上可玩的卡坦島（基本版規則＋5–6 人擴充＋航海家），地圖採鋼鐵雄心式的立體俯視戰略地圖。
- claude.ai 版：https://claude.ai/artifact/HDKAKcGeLm5mr9pntYCbmN
- 自架版（正式）：https://catan-3d.yaoyuanou-ab0.workers.dev （Cloudflare Workers 免費方案）
- 程式碼：https://github.com/Thetoicxdude/catan-3d ，推送到 main 約 2～3 分鐘後自動上線；其他分支有預覽網址（`<版本>-catan-3d.yaoyuanou-ab0.workers.dev`）。主畫面最下方顯示目前版本。

## 已完成

**規則與單機**
- 完整基本版規則：開局擺放、擲骰產出、強盜（棄牌、移動、搶牌）、建造、發展卡、最長道路、最大騎士、港口與銀行交易、玩家間交易。
- 電腦對手（三種難度）、同一台裝置輪流（hot seat）、自動存檔與繼續。
- 規則引擎是純函式、可重播（seed 決定），有單元測試、完整對局模擬與網路序列化測試。

**地圖與操作**
- 立體地形：每塊地形各有地貌（山脈、丘陵、森林、牧場、田地、沙漠），海岸、港口、海浪、雲影。標準島嶼 19 塊，大島嶼（5–6 人）30 塊。
- 鏡頭：可調斜度、可旋轉，Home 回正；拉遠時自動轉成俯視紙地圖。地圖模式：地形、政治、產量熱度、資源。
- 可放置位置用白底黑框圓圈標示；強盜沒有模型（避免穿模），改成被佔領地塊數字牌上的紅色徽章、灰化與通知。

**畫面（第二輪精修）**
- 算圖：環境光照（天空 PMREM）、螢幕空間環境遮蔽（N8AO）、隨鏡頭貼合的陰影、色調與 SMAA 抗鋸齒。
- 村莊：Blend Swap 上 Daniel74 的中世紀木構房屋（CC0），在 Blender 中重建材質並烘焙成單張貼圖（含 AO），屋頂塗上玩家顏色。
- 城市：Poly Haven 城堡模組的圓塔與城牆，加上兩棟木構房屋；塔頂插旗。
- 道路：卵石街道（Poly Haven 照片材質＋法線），路緣石塗玩家顏色，拉遠時整條路染色以便辨識。
- 港口：Poly Haven 的模組化木碼頭、兩種帆船（pinnace、荷蘭大帆船）停泊與航行、貨箱木桶；3:1 港口有石造烽火台與火焰。
- 鄉間：石塔風車（茅草屋頂、木格帆）、金黃草垛、磚窯、礦坑口、沙漠的半埋城牆廢墟，全部使用 Poly Haven 照片材質。
- 樹木：森林改為針闊混交林（新增 Poly Haven 的 island tree 與 small tree 兩種闊葉樹，烘焙成多角度 impostor），牧場有零星闊葉樹。
- 地形：地表材質提高到 1024 px（法線 512 px）；山脈用三向投影岩壁材質（含法線）、更崎嶇的山形與只停在緩坡的積雪；田地的樹籬變細，丘陵的人工橘色圓坑改為自然的黏土開挖面。
- 第三輪：雪山降低約 35%、雪線跟著下修；丘陵（紅土）重做——小沖溝地形、凹處較深較濕、坡上有雨水沖刷紋、碎石地、乾草斑塊與大量低矮灌木。

**資源卡（第三輪）**
- 五張資源卡改用寫實卡面：在 Blender（Cycles）用 CC0 掃描素材擺拍的靜物照——木材（樹皮浮雕的原木堆、年輪與乾裂）、磚塊（手工燒製磚垛與磚場）、羊毛（藤籃裡的生羊毛與毛線球、牧場與羊群）、小麥（捆好的麥束與夕照麥田）、礦石（木桶裡的鐵礦與十字鎬）。
- 上方列的手牌改成五張實體卡（象牙色卡框、銅色數字牌），垂掛在工具列下緣；數量為 0 的卡變灰；手機版排成一列置中。
- 收到資源時，卡面從建築飛進手牌（有光澤掃過），落下時卡片彈跳、數字放大；交易、棄牌、豐收之年、壟斷的選擇視窗都用同一套卡面；戰報、建造花費、港口標示用卡面縮圖。
- 購買發展卡時，卡片在畫面中央翻面，顯示名稱、效果與「下回合起可以使用」，再收進手中。
- 五種發展卡也有寫實卡面（同樣在 Blender 擺拍）：騎士（插在草地上的長劍與圓盾、遠方城堡）、道路建設（鋪到一半的石板路、石材與木槌）、豐收之年（滿籃蘋果與麥穗）、壟斷（天平與金幣）、分數卡（絲絨墊上的王冠）。發展卡視窗與購買動畫都用這些卡面。

**卡牌外框（第四輪）**
- 資源卡與發展卡改用專案提供的六款卡框：木材（深綠）、羊毛（青綠）、小麥（金）、磚塊（紅）、礦石（銀），發展卡用彩虹框；原本的擺拍圖放進拱形窗內，卡背也用彩虹框。
- 卡名以英文哥德體（UnifrakturMaguntia）寫在下方的羊皮紙條上：Lumber、Wool、Grain、Brick、Ore；發展卡為 Knight、Road Building、Year of Plenty、Monopoly、Victory Point。中文名稱在滑鼠停留提示與輔助說明裡。
- 數量改成卡牌右上角的圓形籌碼，不會擋住卡名；上方列的手牌放大到 64 px。
- 建造按鈕（道路、村莊、城市、發展卡）不再在下方列出花費；滑鼠移上去（手機長按）會顯示放大的花費卡、各資源持有數量、效果與目前能否建造的原因。

**試玩回饋（第五輪）**
- 木材卡改用古銅色卡框。
- 港口標示放大：資源卡縮圖＋「2:1」＋資源名稱（3:1 顯示「任意」），拉遠時也維持可讀大小。
- 拉遠後的紙地圖改用每種地形的地圖色（森林深綠、牧場亮綠、田地金黃、丘陵赭紅、山脈石板灰、沙漠沙色），領土顏色變淡、邊界保留；移除雲層。
- 鏡頭不再自動移動（不跟隨電腦行動、不因強盜而移動），只在開局時取景一次。
- 新增「銀行」：在諸國面板上方顯示五種資源與發展卡堆的剩餘張數；蓋建築、買發展卡、棄牌與銀行／港口交易時，資源卡會飛回銀行，數字在卡片抵達時才增加；銀行交易換到的卡、豐收之年從銀行飛出；玩家間交易雙方的卡互相交換飛行。
- 地圖移動與縮放的效能：鏡頭移動時改用較輕的算圖流程（約 65% 解析度、不做環境遮蔽與 SMAA），停下約 0.2 秒後恢復，環境遮蔽淡入；移動中不重算陰影範圍、不重建道路與庭院幾何；不再每格讀取畫布位置；小地圖重繪沿用最近一次的視圖；有後製時畫布不再做多重取樣。
- 畫面品質依顯示晶片自動選擇（內顯如 Intel、AMD Radeon(TM) Graphics 預設「中」，解析度上限 1.0），玩家在設定裡手動選過就照手動的。

**主畫面與試玩回饋（第六輪）**
- 主畫面改成類似 FrontWars 的版面，目的是讓真人都聚到同一個官方房間，而不是各自開房沒人加入：
  - 最上方是官方房間卡片「加入下一場」：顯示下一場官方對戰的島嶼地圖、4 人對戰／10 分勝利／標準規則標籤、目前人數（例如 1/4）與進度條，以及開戰倒數環；整張卡片都能點。
  - 沒有開放中的官方房間時，卡片會說明「按下加入就會開一間：60 秒內湊滿 4 人立即開戰，空位由電腦補上」，並顯示正在配對的人數。
  - 卡片下方依序是單人遊戲（主要按鈕）、建立房間、加入房間、繼續上一局（有存檔時），再下一列是規則說明與設定。
  - 上方有國旗、國家名稱與顏色；右上角顯示「線上 N 人 · M 局進行中」。
  - 單人遊戲的設定（對手、數字排列、勝利分數、換島）移到「單人遊戲」頁，有返回鍵；「加入房間」頁只有房間代碼與開放中的房間列表。
- 官方房間一律用標準規則（10 分、平衡數字），開房的人會在大廳列出島嶼種子，所以主畫面卡片畫的就是下一場真正要玩的島。
- 自架版的主畫面會即時看著大廳（人數、官方房間、倒數）；claude.ai 版沒有自動連線，卡片顯示固定說明，按下後才連線。
- 房間伺服器：只有人在看、沒人改動 presence 的房間（例如主畫面的大廳），清除過期連線的檢查從每 30 秒改為每 2 分鐘，讓房間能在中間休眠。
- 拉到最遠的紙地圖不再泛白：地形色在線性色彩空間中加深、紙張底色與海面都調暗。
- 港口標示重做：圓形資源圖示（卡面特寫＋卡框顏色的外圈；3:1 是五色外圈）加上比例，拿掉文字；標示移到碼頭與船外側的海上，用一條金色細線連回港口所在的海岸；拉遠時跟著縮小（最小 55%），不會蓋住港口。
- 白色陣營改成碧色（#17a9bd，碧海共和國）；舊存檔與設定會自動換色。
- 修正：同一台裝置輪流（hot seat）時，如果第一個放置的是另一位真人玩家，之前不會出現「交給下一位玩家」畫面，遊戲會卡住；現在開局就會先交接。
- 官方配對中剛加入、主持人還沒排好座位的那一兩秒，顯示「正在取得席位…」，不再誤報「房間已滿」。

**主畫面改成遊戲風格（第七輪）**
- 第六輪的版面太像儀表板，這一輪整個換成遊戲的材質：
  - 外框用和資源卡同一套古銅回紋框（從專案提供的卡框裁出的九宮格圖）。
  - 名牌、標籤用卡框裡的羊皮紙。
  - 按鈕與標題用金色浮雕徽章。
  - 標題左邊有六角島嶼徽記。
- 官方房間是一塊地圖板，外框用專案提供的兩張卡框圖：
  - 平常是古銅框（`src/board1.webp`），加入配對後換成金框（`src/board2.webp`）。
  - 兩張圖只有金屬不同，所以用兩張的差異把中間的羊皮紙挖空，只留框（含四邊的月牙徽章）。
  - 框內左邊約 70% 是下一場的島，畫成航海圖：地形小圖示、數字牌、港口、海浪、帆船、羅盤。
  - 框內右邊只有「官方房間」、標籤（4 人對戰、10 分勝利、標準規則）、四面盾牌代表的座位與人數，以及倒數環。
  - 手機上地圖在框內，其餘內容放在框下方的一條。
  - 地圖板會依螢幕放到最大：頁面量出標題列與下方卡牌之間的空間，照卡框原本的比例填滿，不會蓋到其他元件。
    - 1920×1080 約 1229×668。
    - 1280×800 約 803×437。
  - 框內的文字、盾牌與倒數環跟著地圖板一起放大。
- 進官方房間不離開主畫面：
  - 按一下地圖板就加入配對。加入後外框變金色並發光，標題改為「配對中」，你的座位盾牌換成你的顏色，下方提示「再點一次退出」。
  - 再按一次就退出。
  - 按其他按鈕（單人遊戲、建立房間、加入房間、繼續上一局）會先自動退出配對。
  - 房間開戰時直接進入戰役。
- 遊戲方式是一手「卡牌」：單人遊戲（金框）、建立房間（古銅）、加入房間（銅綠）、繼續上一局（銀框，有存檔時）。
  - 卡面窗格裡是大的金色徽章，名稱寫在下方羊皮紙條上，徽章明顯大於文字。
  - 卡牌呈扇形排開，滑鼠移上去會抬起。
- 規則與設定是右下角的兩枚古銅徽章。國家名稱寫在羊皮紙名牌上，顏色是六顆寶石。
- 製作腳本：`tools/art/frames/make_ui.py`（輸出放進 `assets/ui/`）。

**其他（第七輪）**
- 港口模型整體放大 1.6 倍（碼頭、貨物、帆船、3:1 的烽火塔），從戰略視角也看得清楚。
- 右下角地圖面板拿掉旋轉、朝北與斜度控制，只留四個地圖模式（大螢幕仍有小地圖）。
  - 鏡頭照樣可以用右鍵拖曳、Q/E、Z/X、Home 操作。

**遊戲手感**
- 擲骰時兩顆大骰子在畫面中央翻滾落定，點數停留 1 秒後才進行本回合（產出、強盜）；7 顯示「強盜出動」、6/8 顯示「豐收」。
- 資源卡從賺到的村莊/城市飛進手牌（建築會跳一下），每張落下時有音階遞升的提示音，手牌計數逐張增加。
- 建造、最長道路、最大騎士團有勝利點徽章與公告；音效以 WebAudio 即時合成，可在設定關閉。
- 地圖上不再顯示地名；數字牌放大（58 px）。
- 修正（第 7 版）：之前的版本有兩個數字牌錯位問題——一條 CSS 規則把數字牌拉回一般排版流，除了第一張以外全部往下錯位（多數被擠出畫面）；擲出點數時數字牌的放大動畫也會連帶把位置放大，讓牌飛離地塊。現在每個地圖標籤都包在只負責定位的外框裡，動畫只作用在裡面的牌上。UI 測試改用 claude.ai 實際包覆頁面的外框（與發布出去的頁面逐位元組相同），並逐一檢查每個地圖標籤（數字牌、港口、強盜徽章）在靜止與放大動畫中都落在自己的地塊上。

**電腦對手的交易**
- 以前電腦很少接受玩家提議（公平 1 換 1 約 26% 有人接受）。改為評估「換完之後離下一個建設更近多少」、稀缺度與手牌過多的風險，並在快贏的玩家面前保守：公平 1 換 1 有人接受約 43%、2 換 1 約 52%，明顯吃虧的提議約 11%。
- 拒絕時會說明原因：「不需要」或「手上沒有你要的資源」。
- 發展卡規則已確認：當回合買的卡要到自己的下一回合才能用（官方規則；分數卡直接計分）。

**多人**
- 自訂房間：開房、代碼加入、房間列表、斷線重連、觀戰；手牌以 ECDH + AES-GCM 加密。
- 官方房間（類似 FrontWars）：主畫面的「加入下一場」自動配對；滿 4 人 3 秒後開戰，或 60 秒倒數後由電腦補位。
- 在線上大廳與快速配對時，寫實素材的解碼與套用會暫停，等開戰或回到主選單才繼續，避免較慢的裝置因為畫面卡住而在配對中掉線。
- 自架版有自己的房間伺服器（`server/worker.js`，Cloudflare Durable Objects）：與 claude.ai 的 room 功能相同的 presence 模型，伺服器不需要懂規則；支援休眠、同一分頁重連接手、過期連線清除與速率限制。
- 自架版可以複製邀請連結（`網址#room=代碼`），朋友打開就直接進房；重新整理或換新版本後會自動回到原本的席位。
- 主持人的狀態更新會合併（每秒最多約 8 次），大廳的房間列表只在內容改變時送出，避免快速對局時訊息量暴增。

**房間規則（第八輪）**
- 主持人由電腦最好的玩家擔任：開戰後，房主的頁面會比較每位線上玩家的裝置效能（實際跑一小段電腦對局，再依核心數、手機與記憶體調整），有人快 15% 以上就把戰役交給他主持。交接只需一兩秒，戰報會寫「主持改由 X 的電腦負責」。
  - 只交給已經進入戰場、頁面在前景的玩家；交接沒人接手時 10 秒後取消，30 秒後再試。
- 主持人離開也不會中斷戰役：主持人每次更新都把整局狀態（含所有手牌、發展卡順序、骰子亂數）加密給「接班人」（目前效能最好、在線上的玩家）。
  - 主持人按「離開房間」、關閉或重新整理頁面、切到背景（電腦 4 秒、手機立即）：直接交給接班人。
  - 主持人的頁面突然消失：接班人 6 秒後接手；主持人還在但完全沒反應（輪到電腦卻 8 秒沒動作、自己的動作沒被處理、回合時間到了也沒處理）再等 15 秒後接手。
  - 每次換主持人，代數 `ep` 加一；兩個頁面都自認主持人時，代數高的為準，另一個自動改當玩家。
- 有人退出時由電腦代替：按「離開房間」會立刻交給電腦；斷線則 30 秒後交給電腦。之後用同一個瀏覽器回來可以取回自己的國家。
- 回合時間限制（只在線上房間）：開局每次放置村莊與道路 2 分鐘，之後每回合 3 分鐘；擲出 7 時要棄牌的玩家至少有 30 秒。時間到時系統只做最小的動作讓遊戲繼續：開局位置、棄牌、強盜由電腦代選，交易提議撤回或拒絕，沒擲骰就擲骰，最後結束回合；不會替玩家建造或交易。上方列顯示倒數，最後 20 秒變紅。
- 戰報欄多了「聊天」分頁：每則最多 80 字，送出間隔 0.7 秒；訊息放在各自頁面的 presence 裡 20 秒後收回，不經過主持人、也不增加伺服器負擔。面板收合時（手機）新訊息會跳出提示。

**帳號與戰績（第八輪，只在自架版）**

## 自架（Cloudflare Workers 免費方案）
- 一個 Worker 同時提供網頁、素材（約 22 MB，靜態檔案請求不計費）與線上房間（Durable Objects，每個房間一個物件，WebSocket Hibernation）。
- 部署：Workers Builds 連接 GitHub repo，Build command `npm run build`、Deploy command `npx wrangler deploy`；推送到 main 自動部署，其他分支產生預覽網址。主畫面最下方顯示目前版本（commit）。
- 免費額度：Worker 每天 10 萬次請求；Durable Objects 每天 10 萬次請求、13,000 GB-s、寫入 10 萬列；收到的 WebSocket 訊息每 20 則算 1 次請求，送出的訊息與 ping 不計；Workers Builds 每月 3,000 分鐘。
- 本機開發：`npm run dev`（http://127.0.0.1:8787，含房間伺服器）；`node test/rooms.mjs` 測協定，`ROOMS=ws python3 test/online.py` 讓線上測試走真正的房間伺服器；`python3 test/online4.py` 測主持人交接、斷線接手、回合時間與聊天。
- Google 登入：用戶端 ID 寫在 `server/config.js`（公開值，打包時放進網頁）；Google Cloud 的「已授權的 JavaScript 來源」要有 `https://catan-3d.yaoyuanou-ab0.workers.dev`。
- 素材製作腳本放在 `tools/art/`（參考用，原始素材未放進 repo）。
